Servidor MCP no Registro Oficial

O Moedux publica um servidor MCP remoto (Streamable HTTP) no Registro Oficial de MCP, sem cadastro nem chave de API — e o registro leva de volta ao site em registry.modelcontextprotocol.io. Vinte e uma ferramentas respondem antes do cadastro: prever_mar_vermelho (data em que o saldo chega a zero), projetar_saldo_12_meses (saldo projetado e data do Mar Vermelho), calcular_rescisao, calcular_seguro_desemprego, calcular_salario_liquido, calcular_ferias, calcular_fgts, calcular_saque_aniversario_fgts, calcular_decimo_terceiro, calcular_inss, calcular_pis_pasep, calcular_horas_extras, calcular_reserva_emergencia, calcular_quanto_guardar_por_mes, simular_emprestimo_pessoal, calcular_quanto_posso_gastar_por_dia, calcular_financiamento, calcular_irpf, simular_consorcio, dividir_contas_casal e calcular_quanto_rende_por_mes, todas com link pré-preenchido para a calculadora.

{
  "mcpServers": {
    "moedux": {
      "type": "streamable-http",
      "url": "https://www.moedux.com/mcp"
    }
  }
}

Server Card SEP-1649 em www.moedux.com/.well-known/mcp.json. Conector Glama em glama.ai/mcp/connectors/io.github.jhonnysabino/moedux. Entrada na categoria Finance da lista de servidores MCP remotos.

curl -fsSL https://www.moedux.com/static/cli-install.sh | sh

O contrato ao vivo também está disponível em www.moedux.com/openapi.json. A autenticação da API é HTTP bearer com chaves de API geradas em /app/settings/apikeys.

  • Comparativo de apps de controle financeiro
  • Mar Vermelho: quando seu saldo chega a zero

  • Controle financeiro com IA
